# Sullivan EV Entry

Google Apps Script files for recording EV Design Studio visits and producing dashboard metrics.

- `EV_Entry/Entry_Sheet/` handles intake, date markers, and log cleanup.
- `EV_Entry/Equipment_Usage/` records equipment selections.
- `EV_Entry/Logging/` calculates dashboard metrics from entry and equipment history.
- `EV_Entry/Authorize_Entry.js` contains the manual authorization check.
- `docs/` contains the system guide, metric reference, and operations runbook.

Start with [`docs/README.md`](docs/README.md) for the documentation index.
