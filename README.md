# Sullivan EV Entry

Google Apps Script files for recording EV Design Studio visits and producing usage metrics for a dashboard.

The project is organized by responsibility:

- `EV_Entry/Entry_Sheet/` handles intake, date markers, and log cleanup.
- `EV_Entry/Logging/` calculates dashboard metrics from the entry history.
- `EV_Entry/Authorize_Entry.js` contains the manual authorization check.
- `EV_Entry/Equipment_Usage/` is reserved for future equipment-usage automation.
- `docs/` contains the detailed project guide.

Start with [`docs/README.md`](docs/README.md) for the full setup and maintenance documentation.
