# Equipment Usage

`Record_Equipment_Usage.js` handles selections from `Equipment Usage!B1` through the shared installable `processEvEntryEdit` trigger. A selection is inserted at row 2 in column B, timestamped in column C, and then cleared from the dropdown.

See the [project guide](../../docs/PROJECT_GUIDE.md) for the workbook contract and the [operations runbook](../../docs/OPERATIONS_RUNBOOK.md) for trigger setup.
