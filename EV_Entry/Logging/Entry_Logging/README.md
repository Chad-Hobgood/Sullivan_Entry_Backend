# Entry Logging

These functions calculate attendance metrics from `EV Design studio` IDs in column B and timestamps in column F. `Arrival_by_Month.js` groups all available history by recurring month-of-year in August-July order. `runLoggingUpdates` schedules the metrics together; each function can also be run manually.

See the [metric reference](../../../docs/METRIC_REFERENCE.md) for definitions and output ranges.
